## 开发背景

本项目的灵感来源于 [MMmmmoko](https://github.com/MMmmmoko) 大佬开发的 [Bongo-Cat-Mver](https://github.com/MMmmmoko/Bongo-Cat-Mver)。它以独特的猫咪互动功能深受用户喜爱，但仅支持 Windows 平台。
我在[AyangWeb](https://github.com/ayangweb/Awesome-BongoCat)大佬的基础上进行二次开发。
它保留了原版 Live2D 猫咪的键盘、鼠标和手柄互动能力，并加入 AI 聊天、状态气泡、动作与表情自动触发等拟人化交互。




## 功能介绍

新开的功能基本都支持自定义。会给你打招呼，会冒泡。
你给她发生气了，会晴天霹雳；
发抱抱、晚安等安慰话语会头顶出天使光环，晚上熬夜也会出光环，因为原地升天了。
你夸它厉害、真棒、cool等，会戴上墨镜叼根烟，很装很嚣张
聊天框可以点击气泡或者左键双击猫咪唤醒或隐藏。平时就是一只猫在那同步敲键盘动鼠标。

### 桌宠互动

- 跨平台支持 Windows、macOS、Linux(x11)。
- Live2D 模型渲染，键盘、鼠标、手柄输入同步动作。
- 支持导入自定义模型，自由切换标准、键盘和手柄模式。

### AI 聊天

- 双击猫咪打开独立透明聊天窗口。
- 调用 OpenAI 兼容接口，支持 DeepSeek、OpenAI 等主流服务。
- 流式输出、停止生成、本地历史记录。
- 猫咪名称、人格预设、系统提示词、回复后缀、上下文条数均可配置。

### 状态与气泡

- 鼠标悬停猫咪后显示气泡，展示猫咪当前状态、心情和轻提示。
- 长时间无操作时主动弹出“无聊”或“困了”气泡。
- 支持自定义内置文案，并可覆盖各时间段和主动提醒文案。

### 动作与表情

- 根据聊天、悬停、时间和错误状态自动触发动作与表情。
- 保留手动快捷键，动作和表情可同时出现。

### 外观自定义

- 聊天窗口大小、背景色、背景图片、不透明度、文字大小。
- 用户消息和猫咪消息独立配置背景色、不透明度和文字颜色。
- 消息气泡和云朵气泡均带有粉色猫爪装饰。
